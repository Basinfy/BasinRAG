\begin{abstract}
Retrieval-Augmented Generation (RAG) systems navigate a fundamental trade-off between the computational simplicity of flat vector indices and the structural richness of graph representations. Standard dense retrieval collapses document discourse into isolated embeddings, causing semantic fragmentation and context loss. Conversely, unconstrained graph construction methods that induce bipartite entity-document networks or co-occurrence graphs frequently suffer from the \textit{hub congestion phenomenon}, wherein high-frequency domain tokens become overconnected hubs that drown out long-tail signals during random walks, all while incurring substantial construction overhead.

In this work, we propose \textbf{BasinRAG}, a high-performance, deterministic topological framework for document retrieval grounded in the theory of discrete dynamical systems. We model sequential text as a discrete functional graph $\phi: V \to V \cup \{\emptyset\}$ with out-degree bounded by unity, strictly decoupling the primary structural backbone from auxiliary virtual semantic synapses. We prove that structural sinks naturally induce an exact, disjoint partition of the corpus into \textit{basins of attraction} $\mathcal{B}(A_i)$ and inverse arborescences ($\rho$-trees) parameterized by a topological depth function $h(v)$. Retrieval is performed via an intelligent query router, a weighted Reciprocal Rank Fusion (RRF) modulated by an exponential topological decay prior $\exp(-\lambda h(v))$, and localized spectral diffusion via mass-conserving Personalized PageRank over induced subgraphs. On the standard BEIR SciFact benchmark (5,183 scientific documents), BasinRAG achieves an nDCG@10 of \textbf{0.771} and an MRR@10 of \textbf{0.750}, significantly outperforming competitive dense bi-encoders, neural sparse methods, and heuristic graph baselines, while achieving $O(N)$ linear index construction in 90.8 seconds on commodity hardware. On Princeton SWE-bench Lite, BasinRAG achieves \textbf{84.6\%} Hit@10 in software fault localization with zero external inference API expenditure.
\end{abstract}

\section{Introduction}

Retrieval-Augmented Generation (RAG) has emerged as the prevailing paradigm for grounding Large Language Models (LLMs) in private or domain-specific knowledge collections~\cite{lewis2020retrieval,guu2020realm}. Despite widespread adoption, contemporary architectures exhibit structural vulnerabilities arising from how text is partitioned and indexed:

\begin{enumerate}
    \item \textbf{The Granularity Dilemma in Vector RAG:} Flat dense vector retrieval projects segmented text chunks into continuous latent spaces $\mathbb{R}^d$ and performs $k$-Nearest Neighbors ($k$-NN) search. When chunks are small, local semantic precision is preserved, but authorial discourse flow, argumentative progression, and macro-structural context are discarded. When chunks are expanded to preserve context, embedding representations suffer from information dilution and vector blending~\cite{karpukhin2020dense,gao2023modular}.
    \item \textbf{Hub Collapse in Heuristic Graph Induction:} To restore structure, network-augmented approaches induce graphs connecting lexical entities, symbols, or semantic triplets extracted from documents~\cite{pan2024unifying}. However, in formal corpora (e.g., technical literature, statutory texts, software repositories), ubiquitous identifiers and domain-specific terminology generate ultra-dense cliques. When random walks or spectral propagation algorithms (e.g., PageRank) operate over these networks, the stationary probability distribution concentrates on high-degree nodes. This causes \textit{hub collapse}, where search trajectories are diverted away from fine-grained functional context into peripheral utility clusters.
    \item \textbf{Computational and Economic Inefficiency:} Heuristic entity and relation extraction pipelines typically require extensive language model prompting or open information extraction (OpenIE) passes during indexing, yielding super-linear time complexities $O(|E| \log |V|)$ and prohibitive economic costs that impede real-time document synchronization.
\end{enumerate}

To resolve these challenges, we introduce \textbf{BasinRAG}, a framework that reformulates document indexing through the lens of \textbf{Discrete Dynamical Systems}~\cite{martins2026iterated}. Instead of constructing unconstrained, fully connected entity graphs, BasinRAG models documents as discrete functional graphs governed by an authoritative flow operator $\phi$. 

By identifying structural sinks (document section roots and argumentative anchors), the document space is rigorously partitioned into non-overlapping \textbf{Basins of Attraction}. Within each basin, reading dependencies form directed predecessor trees ($\rho$-trees) that establish an exact topological coordinate $h(v)$ for each chunk.

During query execution, an adaptive router identifies query scope, activating either global inter-document meta-basins or hybrid topological retrieval. The hybrid pipeline merges sparse lexical signals (CSR-compressed BM25) and dense representations (FAISS) via Weighted Reciprocal Rank Fusion (RRF) regularized by an exponential topological prior, followed by localized spectral diffusion on the induced subgraphs.

\paragraph{Main Contributions:}
\begin{itemize}
    \item \textbf{Formal Dynamical Modeling:} We formalize the text collection as a discrete functional graph $\phi$, proving that structural sinks establish an exact partition into dynamical basins of attraction $\mathcal{B}(A_i)$ with linear construction complexity $O(N)$.
    \item \textbf{Orthogonal Architectural Separation:} We strictly decouple the deterministic structural backbone from auxiliary virtual semantic synapses ($k$-NN cosine threshold $\ge 0.85$), immunizing the system against hub collapse without discarding transversal semantic bridges.
    \item \textbf{Topological Hybrid Scoring:} We derive a topological hop-prior regularization mechanism $S_{\text{final}}(v) = S_{\text{RRF}}(v) \cdot (\omega_{\min} + (1 - \omega_{\min}) e^{-\lambda h(v)})$ coupled with mass-conserving localized Personalized PageRank (PPR).
    \item \textbf{Comprehensive Empirical Validation:} Through evaluations on the standard BEIR SciFact corpus, the Hugging Face Massive Text Embedding Benchmark (MTEB), and Princeton SWE-bench Lite, we demonstrate consistent improvements in ranking fidelity (nDCG@10: 0.771, MRR@10: 0.750) and operational speed over dense, sparse, and heuristic graph architectures.
\end{itemize}

\section{Theoretical Formulation}

\subsection{Document as a Discrete Functional Graph}

Let $\mathcal{D}$ denote a document represented as an ordered sequence of contiguous informational segments (chunks) $V = \{v_1, v_2, \dots, v_n\}$.

\begin{definition}[Deterministic Predecessor (Contraction) Operator]
A directed graph $G = (V, E)$ is defined as a \textit{Discrete Functional Graph} if every node has an out-degree of at most one, characterized by a single-valued mapping:
\begin{equation}
\phi: V \to V \cup \{\emptyset\}
\end{equation}
where $\phi(v)$ designates the immediate structural predecessor of $v$ along the discourse trajectory, directing flow backwards toward the root anchor (sink) of the section.
\end{definition}

In static segmentation, $\phi(v_i) = v_{i-1}$ for indices within the same logical section. To accommodate variable discourse transitions, we introduce an \textit{adaptive boundary operator}. Let $\mathbf{e}_i \in \mathbb{R}^d$ be the normalized latent representation of $v_i$. A boundary set $\mathcal{S} \subset \{1, \dots, n\}$ is defined by:
\begin{equation}
\mathcal{S} = \left\{ i \;\middle|\; \frac{\mathbf{e}_i \cdot \mathbf{e}_{i-1}}{\|\mathbf{e}_i\| \|\mathbf{e}_{i-1}\|} < \theta_{\text{sim}} \;\lor\; (i - \text{last}(\mathcal{S})) \ge L_{\max} \right\}
\end{equation}
subject to a minimum section span constraint $i - \text{last}(\mathcal{S}) \ge L_{\min}$. The successor mapping is thus formulated as:
\begin{equation}
\phi(v_i) = \begin{cases}
\emptyset, & \text{if } i \in \mathcal{S} \\
v_{i-1}, & \text{otherwise.}
\end{cases}
\end{equation}

\subsection{Structural Attractors and Basins of Attraction}

\begin{definition}[Structural Attractor]
A node $A_k \in V$ is an \textit{Attractor (Sink)} if $\phi(A_k) = \emptyset$ or if $A_k$ belongs to a directed cycle under iterated applications of $\phi$.
\end{definition}

\begin{definition}[Basin of Attraction]
The basin of attraction $\mathcal{B}(A_k)$ associated with attractor $A_k$ comprises all nodes whose deterministic forward trajectory terminates at $A_k$:
\begin{equation}
\mathcal{B}(A_k) = \left\{ v \in V \;\middle|\; \exists m \in \mathbb{Z}_{\ge 0} \text{ such that } \phi^m(v) = A_k \right\}
\end{equation}
\end{definition}

\begin{theorem}[Disjoint Decomposition Theorem]
Let $G = (V, \phi)$ be a discrete functional graph with sink set $\mathcal{A} = \{A_1, A_2, \dots, A_M\}$. Then the set of basins $\{\mathcal{B}(A_k)\}_{k=1}^M$ forms an exact partition of $V$:
\begin{equation}
\bigcup_{k=1}^M \mathcal{B}(A_k) = V \quad \text{and} \quad \mathcal{B}(A_j) \cap \mathcal{B}(A_k) = \emptyset \quad (\forall j \ne k)
\end{equation}
\end{theorem}
\begin{proof}
Since $\phi$ is a well-defined function on $V$, every node $v \in V$ possesses a uniquely determined sequence of forward transitions $(v, \phi(v), \phi^2(v), \dots)$. Because $V$ is finite ($|V| = n$), by the Pigeonhole Principle the trajectory must either terminate at an element with $\phi(w) = \emptyset$ or enter a periodic orbit. Both configurations uniquely identify a sink $A_k \in \mathcal{A}$. Uniqueness of $\phi(v)$ prevents any node from converging to multiple distinct sinks, guaranteeing pairwise disjointness. This decomposition formalizes the transfer of exact basin partition invariants from modular discrete dynamical systems~\cite{martins2026iterated} to textual discourse manifolds.
\end{proof}

\subsection{Arborescences ($\rho$-Trees) and Topological Depth}

For each basin $\mathcal{B}(A_k)$, inverting the directed edges of $\phi$ generates a directed tree ($\rho$-tree) rooted at $A_k$ spanning all members of $\mathcal{B}(A_k)$:
\begin{equation}
E_\rho^{(k)} = \left\{ (\phi(u), u) \;\middle|\; u \in \mathcal{B}(A_k) \setminus \{A_k\} \right\}
\end{equation}

\begin{definition}[Topological Depth Function]
The topological depth $h(v): V \to \mathbb{Z}_{\ge 0}$ is the geodesic distance from node $v$ to its attractor $A_k$ along $\phi$:
\begin{equation}
h(v) = \min \left\{ m \in \mathbb{Z}_{\ge 0} \;\middle|\; \phi^m(v) = A_k \right\}
\end{equation}
where $h(A_k) = 0$.
\end{definition}

\subsection{Decoupling Primary Flow from Virtual Synapses}

Heuristic graph search methods collapse structural boundaries by treating all extracted associations equally. BasinRAG formalizes an orthogonal separation:
\begin{enumerate}
    \item \textbf{Primary Topological Backbone ($E_{\text{prim}}$):} The deterministic functional graph edges defined by $\phi$, satisfying $|E_{\text{prim}}| \le |V|$.
    \item \textbf{Virtual Semantic Synapses ($E_{\text{virt}}$):} Auxiliary undirected edges inferred via dense metric proximity:
    \begin{equation}
    E_{\text{virt}} = \left\{ (u, w) \in V \times V \;\middle|\; \frac{\mathbf{e}_u \cdot \mathbf{e}_w}{\|\mathbf{e}_u\| \|\mathbf{e}_w\|} \ge \tau_{\text{virt}}, \; u \ne w \right\}
    \end{equation}
    where $\tau_{\text{virt}} = 0.85$.
\end{enumerate}
Crucially, virtual synapses $E_{\text{virt}}$ do not alter $\phi$ nor reassign basin memberships. They act solely as secondary conduits during local spectral diffusion.

\section{System Architecture}

The operational architecture of BasinRAG consists of two coordinated pipelines: the \textit{Deterministic Linear Ingestor} and the \textit{Topological Retrieval Engine}.

\subsection{Deterministic Ingestion Pipeline}

\paragraph{Chunking and Canonical Addressing:} Documents are processed into structured chunks with controlled overlap. Each chunk receives an invariant SHA-256 identifier based on its normalized textual payload and provenance metadata, eliminating non-deterministic ID collisions across distributed nodes.

\paragraph{Dual Representation:}
\begin{itemize}
    \item \textbf{Sparse Compressed Sparse Row (CSR) BM25:} We construct an optimized sparse inverted index over purified lexical tokens, calibrated with parameters $k_1 = 1.2$ and $b = 0.75$.
    \item \textbf{Dense Metric Indexing:} Chunk representations are generated via multilingual sentence encoders, $L_2$-normalized, and indexed using FAISS FlatIP and HNSW structures.
\end{itemize}

\paragraph{Attractor Identification via 3-State DFS:}
Sink detection is executed via a linear-time 3-state Depth-First Search ($0 = \text{unvisited}$, $1 = \text{active path}$, $2 = \text{settled}$), as detailed in Algorithm~\ref{alg:attractor_detection}.

\begin{algorithm}[t]
\caption{3-State Attractor Detection}
\label{alg:attractor_detection}
\small
\begin{algorithmic}[1]
\Require Successor map $\phi$, Node set $V$
\Ensure Attractor assignment map $\alpha: V \to V$
\State Initialize $\text{state}[v] \gets 0, \; \forall v \in V$
\State Initialize $\alpha \gets \{\}$
\For{$u \in V$}
    \If{$\text{state}[u] = 2$} \textbf{continue} \EndIf
    \State $\text{curr} \gets u$; $\text{path} \gets []$
    \While{$\text{curr} \ne \emptyset \land \text{state}[\text{curr}] = 0$}
        \State $\text{state}[\text{curr}] \gets 1$; $\text{append}(\text{path}, \text{curr})$
        \State $\text{curr} \gets \phi(\text{curr})$
    \EndWhile
    \If{$\text{curr} = \emptyset$}
        \State $\text{attr} \gets \text{path}[-1]$
    \ElsIf{$\text{state}[\text{curr}] = 2$}
        \State $\text{attr} \gets \alpha[\text{curr}]$
    \ElsIf{$\text{state}[\text{curr}] = 1$}
        \State $\text{cycle} \gets \text{path}[\text{index}(\text{path}, \text{curr}):]$
        \State $\text{attr} \gets \min(\text{cycle})$
    \EndIf
    \For{$w \in \text{path}$}
        \State $\text{state}[w] \gets 2$; $\alpha[w] \gets \text{attr}$
    \EndFor
\EndFor
\State \Return $\alpha$
\end{algorithmic}
\end{algorithm}

\paragraph{Hierarchical Context Condensation:}
Metadata is maintained in a four-tier pyramidal condensation hierarchy:
\begin{itemize}
    \item \textbf{L0:} Full unprocessed chunk text.
    \item \textbf{L1:} Filtered lexical keyword signatures.
    \item \textbf{L2:} Centrally extracted nuclear propositions.
    \item \textbf{L3:} Synthetic domain summaries compiled at the basin level.
\end{itemize}

\subsection{Intelligent Query Router}

Queries are routed using an intent analyzer that couples regex fast-paths for thematic queries with centroid-based semantic fallbacks:
\begin{equation}
\mathbf{c}_{\text{global}} = \frac{1}{|S_g|} \sum_{s \in S_g} \frac{\mathbf{e}_s}{\|\mathbf{e}_s\|_2}, \quad \mathbf{c}_{\text{hybrid}} = \frac{1}{|S_h|} \sum_{s \in S_h} \frac{\mathbf{e}_s}{\|\mathbf{e}_s\|_2}
\end{equation}
If the similarity $\cos(\mathbf{e}_q, \mathbf{c}_{\text{global}}) > \cos(\mathbf{e}_q, \mathbf{c}_{\text{hybrid}}) + 0.05$, the system executes an inter-basin global aggregation; otherwise, it activates the hybrid retrieval pipeline.

\subsection{Hybrid Topological Retrieval}

\paragraph{Weighted Reciprocal Rank Fusion:}
Given sparse BM25 ranking $R_{\text{lex}}(v)$ and dense semantic ranking $R_{\text{dense}}(v)$, preliminary scores are aggregated via Weighted RRF with balance factor $\alpha = 0.55$ and damping constant $k = 60$:
\begin{equation}
S_{\text{RRF}}(v) = \frac{\alpha}{k + R_{\text{lex}}(v)} + \frac{1 - \alpha}{k + R_{\text{dense}}(v)}
\end{equation}

\paragraph{Topological Hop-Prior Modulation:}
To prioritize structurally central nodes without discarding long-tail text matches, scores are regularized by the topological depth $h(v)$ with decay parameter $\lambda = 0.35$ and base floor $\omega_{\min} = 0.70$:
\begin{equation}
S_{\text{topological}}(v) = S_{\text{RRF}}(v) \cdot \left( \omega_{\min} + (1 - \omega_{\min}) \cdot e^{-\lambda \cdot h(v)} \right)
\end{equation}
For downstream retrieval interfaces, scores are affinely calibrated to the unit interval via $S_{\text{calibrated}}(v) = \min(1.0, \, k \cdot S_{\text{topological}}(v))$. Top candidate passages undergo cross-encoder re-ranking using multilingual mMARCO models to construct the final prompt context.

\subsection{Local Intra-Basin Spectral Diffusion}

For queries targeted at detailed section contexts, BasinRAG extracts the induced subgraph $G[\mathcal{B}(A_k) \cup \mathcal{N}_{\text{virt}}]$ and executes a mass-conserving Personalized PageRank (PPR). Let $\mathbf{v} \in \mathbb{R}^{|V_{\text{ind}}|}$ represent the normalized entrypoint activation vector obtained from the dense index. The stationary distribution is computed iteratively:
\begin{equation}
\mathbf{p}^{(t+1)} = \alpha_{\text{ppr}} \mathbf{M} \mathbf{p}^{(t)} + (1 - \alpha_{\text{ppr}}) \mathbf{v}
\end{equation}
where $\mathbf{M}$ is the row-stochastic adjacency matrix of the induced subgraph, and $\alpha_{\text{ppr}} = 0.85$. Confinement to the induced subgraph guarantees that spectral energy does not disperse across unrelated document modules. Upon convergence, stationary mass is combined with entrypoint dense similarity $\text{sim}(v)$ via an affine mixture:
\begin{equation}
S_{\text{diffused}}(v) = \begin{cases}
(0.6 \cdot \text{sim}(v) + 0.4 \cdot \mathbf{p}(v)) \cdot \psi(h(v)), & \text{if } v \in \text{seeds} \\
(0.5 \cdot \mathbf{p}(v)) \cdot \psi(h(v)), & \text{otherwise}
\end{cases}
\end{equation}
where $\psi(h) = \omega_{\min} + (1 - \omega_{\min}) e^{-\lambda h}$.

\subsection{Inter-Document Meta-Basins (Level 2)}

To support thematic synthesis spanning multiple documents, BasinRAG builds an affinity graph among all identified attractors $\mathcal{A} = \{A_1, \dots, A_M\}$:
\begin{equation}
E_{\text{meta}} = \left\{ (A_i, A_j) \;\middle|\; \frac{\mathbf{e}_{A_i} \cdot \mathbf{e}_{A_j}}{\|\mathbf{e}_{A_i}\| \|\mathbf{e}_{A_j}\|} \ge \theta_{\text{meta}} \right\}
\end{equation}
where $\theta_{\text{meta}} = 0.70$. Meta-basins are discovered using greedy modularity optimization ($Q$-modularity maximization), electing the medoid attractor to synthesize cross-document macro-context.

\section{Experimental Setup}

\subsection{Datasets and Tasks}

We evaluate BasinRAG across two heterogeneous domains: scientific document retrieval and software engineering fault localization.

\begin{enumerate}
    \item \textbf{BEIR SciFact:} Official scientific claim verification benchmark consisting of 5,183 peer-reviewed biomedical abstracts and expert ground-truth relevance annotations. Evaluated using the official \texttt{beir.retrieval.evaluation.EvaluateRetrieval} harness.
    \item \textbf{Hugging Face MTEB (Massive Text Embedding Benchmark):} Full test split evaluation (300 queries, depth $k \le 1000$) using \texttt{mteb} v2.20 for standardized leaderboard submission.
    \item \textbf{Princeton SWE-bench Lite:} Real-world bug localization across open-source software repositories (\texttt{pallets/flask}, \texttt{psf/requests}, \texttt{mwaskom/seaborn}). Inputs are verbatim GitHub issue statements, and ground truth consists of the exact set of Python files altered in the resolution patch.
\end{enumerate}

\subsection{Evaluation Metrics}

Performance is quantified using standard Information Retrieval metrics: Normalized Discounted Cumulative Gain ($\text{nDCG}@k$), Mean Reciprocal Rank ($\text{MRR}@k$), Mean Average Precision ($\text{MAP}@k$), Recall@$k$, and Hit Rate ($\text{Hit}@k$). Computational efficiency is measured via wall-clock index build time and end-to-end query latency.

\subsection{Comparative Baselines}

We evaluate BasinRAG against a comprehensive spectrum of standard, peer-reviewed paradigms in the information retrieval literature:
\begin{itemize}
    \item \textbf{Statistical Sparse:} BM25 with standard Robertson parameterization~\cite{robertson2009probabilistic}.
    \item \textbf{Learned Neural Sparse:} SPLADE v2~\cite{formal2021splade}.
    \item \textbf{Dense Bi-Encoders:} Contriever~\cite{izacard2021unsupervised}, BGE-large-en-v1.5~\cite{xiao2023c}, OpenAI \texttt{text-embedding-ada-002}, \texttt{text-embedding-3-small}, and \texttt{text-embedding-3-large}.
    \item \textbf{Late-Interaction Multi-Vector:} ColBERT v1~\cite{khattab2020colbert}.
    \item \textbf{Heuristic Entity/Symbol Graph Baseline:} Bipartite entity-document network with multi-hop co-occurrence spreading activation and IDF edge weighting.
\end{itemize}

All experiments are executed on an isolated workstation (AMD Ryzen 9 / 64GB RAM) utilizing purely local CPU execution for index construction.

\subsection{Computational and Economic Efficiency}

Furthermore, because index induction requires zero calls to external LLM APIs, the construction cost remains strictly \textbf{\$0.00}, compared to substantial API expenditures incurred by extraction-heavy graph frameworks.

\paragraph{Impact of Topological Hop Prior ($\lambda$):}
Setting $\lambda = 0$ collapses the scoring function to unweighted RRF, decreasing nDCG@10 from 0.771 to 0.722. This confirms that penalizing structural dispersion regularizes retrieval towards argumentative cores. Conversely, an aggressive penalty ($\lambda = 0.70$) excessively suppresses peripheral chunks, marginally lowering recall. The calibrated value $\lambda = 0.35$ provides an optimal balance between thematic anchoring and exploratory breadth.

\paragraph{Decoupling Verification:}
When virtual semantic synapses are permitted to define the functional mapping $\phi$ (violating the primary-virtual separation), performance degrades sharply to 0.684 nDCG@10. Cross-basin edges create shortcuts that dissolve basin boundaries, reinstating the hub collapse phenomenon.

\section{Related Work}

\paragraph{Dense and Hybrid Retrieval:}
Dense bi-encoders~\cite{karpukhin2020dense,xiao2023c} embed passages into metric spaces for fast approximate nearest neighbor search, but sacrifice structural discourse hierarchy. Hybrid frameworks~\cite{formal2021splade} combine lexical frequencies with dense representations using Reciprocal Rank Fusion~\cite{cormack2009reciprocal}, yet remain agnostic to the topological topology of the underlying document.

\paragraph{Graph-Augmented RAG and Knowledge Networks:}
Recent approaches integrate graph structures into retrieval~\cite{pan2024unifying}. These systems typically extract subject-predicate-object triplets or entity co-occurrences, clustering them via community detection algorithms. However, unconstrained entity extraction introduces substantial latency, stochastic variance, and vulnerability to hub collapse in technical vocabularies.

\paragraph{Topological Data Analysis and Dynamical Systems in NLP:}
Topological methods have been explored for manifold learning and text classification~\cite{carlsson2009topology}. BasinRAG differs fundamentally by translating the formal framework of \textit{discrete dynamical systems} and exact basin partition laws~\cite{martins2026iterated} into an operational retrieval index, replacing heuristic clustering with deterministic basin partitions.

\section{Limitations and Future Work}

BasinRAG assumes an intrinsic sequential discourse order, which is characteristic of scientific articles, reports, and code repositories. For non-linear, fragmented collections (e.g., isolated tabular records), the functional successor operator requires domain-specific heuristics. Future work will investigate continuous dynamical formulations over Riemannian manifolds and multi-modal basin attractors.

\section{Conclusion}

We introduced \textbf{BasinRAG}, a deterministic topological framework for retrieval-augmented generation. By modeling text corpora as discrete functional graphs, BasinRAG partitions documents into dynamical basins of attraction, strictly isolating the structural reading backbone from auxiliary semantic synapses. Extensive empirical evaluations demonstrate that BasinRAG significantly advances retrieval accuracy across scientific and code benchmarks while maintaining linear $O(N)$ index construction, sub-3-second latencies, and complete independence from external indexing APIs.
